## 🌟 About the Project

The **Advanced To-Do List** is a simple and interactive task manager made with HTML, CSS and JavaScript.

It allows users to add tasks, mark them as completed, change their order and delete them when they are no longer needed. The interface uses a dark background with golden accents for a clean, focused look.

## ✨ Features

- ➕ **Add Task:** Add a new task to the list.
- ☑️ **Mark Complete:** Use the checkbox to mark a task as completed.
- ↩️ **Move Up:** Move a task one position upward.
- ↪️ **Move Down:** Move a task one position downward.
- 🗑️ **Delete Task:** Remove a task from the list.
- ⚠️ **Empty Input Check:** Shows an alert if you try to add a blank task.
- 🎨 **Dark & Gold UI:** A simple interface with contrasting colors.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and task elements |
| CSS3 | Styling, layout and completed-task appearance |
| JavaScript | Adding, completing, reordering and deleting tasks |

## ⚙️ How It Works

1. The user enters a task in the input field.
2. JavaScript reads the value and removes extra spaces using `trim()`.
3. If the input is empty, an alert is displayed.
4. A new list item is created dynamically.
5. A checkbox toggles the `completed` CSS class.
6. The Up and Down buttons rearrange list items using DOM methods.
7. The Delete button removes the selected task.

## 🚀 Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Anurag996/Advanced-To-Do-List.git
   ```
2. Open the project folder.
3. Open `ADVANCED-TODO-LIST.html` in your browser.
4. Enter a task and try the available controls.

> If your repository or HTML filename is different, replace the clone URL or filename with your actual one.
