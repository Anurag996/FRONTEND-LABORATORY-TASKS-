## 👋 About This Repository

Welcome to my mini-project collection! This repository contains two beginner-friendly front-end projects created using **HTML, CSS and JavaScript**.

Each task focuses on practical JavaScript concepts such as DOM manipulation, event handling, creating elements dynamically and responding to user interactions.

---

## 📌 Projects Included

### 1. 📝 To-Do List

A simple task manager that helps users add and remove tasks through a clean, dark-and-gold interface.

**Features**
- ➕ Add a new task.
- 🗑️ Delete a task from the list.
- ⚠️ Prevent empty tasks with input validation.
- ✨ Automatically clear and refocus the input after adding a task.
- ⚡ Create task elements dynamically with JavaScript.

**JavaScript concepts used**
- `getElementById()`
- `addEventListener()`
- `trim()` for input validation
- `createElement()` and `appendChild()`
- `remove()` for deleting tasks

**Project file:** `TODO-LIST.html`

---

### 2. 🖼️ Image Gallery

An interactive image gallery where users can click a thumbnail to display the selected image in a larger preview area.

**Features**
- 🖼️ Large main image preview.
- 🔎 Multiple clickable thumbnail images.
- 🖱️ Click a thumbnail to change the main image.
- 🎨 Hover effect on thumbnails.
- 📱 Flexible thumbnail layout using CSS Flexbox.

**JavaScript concepts used**
- `getElementById()`
- `querySelectorAll()`
- `forEach()` to handle all thumbnails
- `addEventListener()` for click events
- `dataset` to access the `data-large` image attribute
- Updating image `src` and `alt` dynamically

**Project file:** `MAKINGGALLERY.html`
