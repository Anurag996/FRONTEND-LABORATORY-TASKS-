# 🧩 TASK 1 — Personal Introduction

## 🎯 Objective

Create a webpage that introduces a person by storing their **name, age, course and section** in JavaScript variables.

## 🛠️ Concepts Used

- 🧾 `let` and `const` variables
- 🏷️ HTML headings and paragraphs
- 🎨 Basic CSS styling
- 🖥️ Displaying JavaScript values on a webpage

## 💻 JavaScript Example

```javascript
let name = "Anurag Prajapati";
let age = 19;
let course = "B.Tech Computer Science";
let section = "FA";

console.log("Name: " + name);
console.log("Age: " + age);
console.log("Course: " + course);
console.log("Section: " + section);
```

## 📤 Expected Output

```text
Name: Anurag Prajapati
Age: 19
Course: B.Tech Computer Science
Section: FA
```

> ℹ️ Update the age, course or section values if your details are different.

## ▶️ How to Run

1. Create an `index.html` file.
2. Add the HTML structure and a `<script>` section, or link an external JavaScript file.
3. Save the file and open it in a browser.
4. Open the browser console to view the `console.log()` output.

## 📖 What I Learned

- How to declare variables in JavaScript.
- How to store text and numeric values.
- How to print values using `console.log()`.
- How JavaScript can provide information for an HTML webpage.
