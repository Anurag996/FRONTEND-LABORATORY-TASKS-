# 🧩 TASK 3 — Favourite Things

## 🎯 Objective

Store favourite **food, colour and movie** in JavaScript variables and display three sentences describing them.

## 🛠️ Concepts Used

- ❤️ String variables
- 🧾 `let` and `const`
- 🔗 String concatenation with `+`
- 🖥️ `console.log()` output

## 💻 JavaScript Example

```javascript
let food = "Pizza";
let colour = "Black";
let movie = "Interstellar";

console.log("My favourite food is " + food + ".");
console.log("My favourite colour is " + colour + ".");
console.log("My favourite movie is " + movie + ".");
```

## 📤 Expected Output

```text
My favourite food is Pizza.
My favourite colour is Black.
My favourite movie is Interstellar.
```

> ℹ️ These are sample values. Replace them with your own favourites if needed.

## ▶️ How to Run

1. Create an `index.html` file.
2. Add the JavaScript code inside a `<script>` tag or a separate `.js` file.
3. Open the HTML file in a browser.
4. Open the browser console to see the three sentences.
