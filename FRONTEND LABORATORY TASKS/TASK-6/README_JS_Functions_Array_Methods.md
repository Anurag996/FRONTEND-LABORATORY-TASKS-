## 🌟 About the Project

This project is a collection of JavaScript examples covering **functions, closures, IIFE and commonly used array methods**.

The examples are written in a simple way to understand how JavaScript functions return values, preserve variables and process array data.

## 📚 Topics Covered

### 1. Functions
A function named `calculateTotal(price, quantity)` calculates the total price by multiplying price and quantity.

**Example:** `calculateTotal(100, 3)` returns `300`.

### 2. Closure
The `counter()` function returns an inner function that remembers and updates the `count` variable between calls.

- Starts with `count = 0`.
- Each call increments the count by 1.
- The returned function is stored in `increment`.

### 3. IIFE (Immediately Invoked Function Expression)
An IIFE is a function that runs immediately after it is defined. In this example, it prints the message `"This is an IIFE"`.

### 4. Array Methods

The project uses the array:

```javascript
const numbers = [10, 20, 30, 40, 50];
```

| Method | Purpose in this project | Result |
|---|---|---|
| `map()` | Doubles every number | `[20, 40, 60, 80, 100]` |
| `filter()` | Selects numbers greater than 25 | `[30, 40, 50]` |
| `reduce()` | Calculates the sum of all numbers | `150` |
| `forEach()` | Prints each number one by one | `10, 20, 30, 40, 50` |
